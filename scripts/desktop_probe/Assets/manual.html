后台启动与解锁

打开栖伴后由应用准备本机后台（数据库与加密后台）。首页状态区显示当前进度，未就绪时其他操作保持不可用。

若已开启应用密码锁，先解锁再进行本机管理。忘记密码时，可设置新密码并通过 Windows 验证当前身份重设；现有资料保留，应用密码锁继续开启。

关闭窗口只会收至托盘，再次打开回到原窗口。退出应用遵循现行退出流程。

平台登录

QQ：扫码登录后选择要用于栖伴的账号并保存。微信：确认本机微信已登录的账号并使用它。B 站：按扫码流程授权，保存后可在线只读核对账号。

登录不等于运行。登录只保存账号与凭据，平台默认保持停止；不会因为登录而开始回复、互动或消耗模型额度。

会话名单

QQ：保存账号后读取好友和群名称，勾选要回复的会话，核验通过后保存。保存会替换该账号当前的手动回复范围；两个列表都留空并保存，即清空手动名单。核验要求所选会话当前仍能被发现，已保存会话暂时不可见时需先从名单移除再核验。

微信：读取当前账号的好友与群目录，勾选并核验后保存回复名单。此前已保存的勾选会保留，即使当前目录暂时不可见；新勾选的会话必须当前可见，未通过核验的会话会被列出。

修改名单前需先停止该平台运行。持续授权（例如允许所有好友或群）单独保存，并按现行规则要求平台停止。单会话排除只停用该会话，解除后只回应解除之后的新消息。

模型账号

在模型账号区检查登录状态、发起登录或切换已保存的账号。模型登录本身不产生对话、任务或平台发送；实际调用仍受当前授权与额度限制。

回复额度与排除

回复额度页显示各账号与会话的额度、今日用量和授权状态，可对已核验账号与已登记会话调整额度；离线时也能保存，但不会改变回复授权、不启动或停止平台。

单会话的停用与解除在该页按现行规则执行，只影响目标会话；其他会话、账号与平台保持原状。

会客室与手动任务

会客室只在本机使用，随应用锁一起遮挡历史与草稿，读写需要当前解锁身份。

手动任务只执行本次明确提交的要求，不改变自动运行设置。取消、停止全部或退出应用会终止任务；更换模型账号后由新账号接续未完成步骤。

资料与备份

本机备份与恢复支持列出、创建备份，恢复前先预览并核对内容。恢复会生成新的资料代次，当前资料与原只读副本继续保留。

跨电脑完整替换恢复需要先保全当前资料、预览影响并通过 Windows 管理验证；不迁移 0.9.4 的测试资料库。资料共享、人际关系声明与其他治理入口各自独立，普通编辑不会放宽共享范围。

运行、停止与恢复

全新安装时自动运行默认关闭。保存自动运行偏好后，下次打开栖伴会按该偏好逐个检查账号、模型等就绪条件，通过后才启动。本次打开期间主动停止的平台不会因重连自动运行，下次打开仍按保存的偏好检查；恢复资料后的平台保持停止，需要手动核对后启动。

停止会等到在途操作收尾。退出等待、明确强制结束与再次启动后的恢复检查遵循现行规则；结果不明的发送不会自动重发。

网页管理页与 Codex 管理聊天入口已经停止使用，相关命令行入口也不再启动旧服务。请始终通过栖伴应用完成管理。
