后台启动与解锁

打开栖伴后，统一监控台会显示后台连接、各平台和当前活动。点击平台名称可展开运行操作。暂停观察会停留在当前快照，后台任务继续执行。

开启应用密码锁后，先解锁再管理。忘记密码时，可通过 Windows 验证身份设置新密码；现有资料保留，密码锁继续开启。

关闭窗口时可选择退出应用、后台运行或取消。

平台登录

QQ 和 B 站可扫码登录；微信先在电脑微信登录，再回到栖伴检测账号。

登录不等于运行。平台默认保持停止；不会自动回复、互动或消耗额度。

会话名单

QQ：读取好友和群列表，勾选需要回复的会话，核验后保存。保存会替换当前名单；两个列表都清空后保存即清空名单。

微信：读取好友和群，勾选并核验后保存回复名单。已保存的勾选保留；新勾选的会话必须当前可见。

修改名单前先停止该平台。持续授权（允许所有好友或群）单独保存。停用单个会话只影响该会话；解除后不补回停用期间的消息。

模型账号

在「模型与档位」切换模型，页面会列出该模型支持的思考强度。查看「当前生效」可核对保存结果。「账号管理」页签可以登录或切换已保存的账号。

回复额度与排除

回复额度页显示额度、今日用量和授权状态。调整额度不会改变回复授权，也不会启停平台。

停用单个会话只影响该会话，其他会话和账号不变。

会客室与手动任务

会客室只在本机使用；锁定时会遮挡历史和草稿。

手动任务只执行本次提交的内容，不改自动运行设置。取消、停止全部或退出应用会终止任务；更换模型账号后由新账号接续未完成步骤。

自主事项与角色提醒

监控台的「最近行动」按最近变动列出最多十条事项。点事项标题可直接查看该项行动、收件会话和进度。点「查看事项」可进入「任务与记录 → 自主事项」的完整列表。「等待新消息」表示事项正在等消息，「等待唤醒」旁显示本地时间。

点「停止续办」后，先前的投递回执仍会保留。「投递已确认」表示消息已确认投递，「投递结果不明」表示尚无确定回执。要调整提醒，打开同页的「角色提醒」，展开记录后可按提供的操作改期或取消。

隐私使用范围

在「人物与记忆 → 资料共享」展开「隐私使用范围」，可以逐条查看片段的受众。从某条资料的详情点「查看此资料的隐私范围」，只显示这条资料的片段。

后台审查期间，片段维持原范围。展开已审查的片段，选择可用的范围后点「保存范围」。凭据以遮盖后的记录显示。

资料与备份

在「设置与备份」选择本机备份、便携备份或本机保全资料。恢复前先核对预览，再通过 Windows 验证确认；当前资料会保留。

跨电脑恢复是完整替换：先保全当前资料、预览影响并通过 Windows 验证。

运行、停止与恢复

自动运行默认关闭。保存偏好后，下次打开栖伴会先检查账号、模型等条件，通过后才启动。本次打开时手动停止的平台不会自动重连；恢复资料后需手动启动。

停止会等待在途操作完成；结果不明的发送不会自动重发。
