高级资料导入与导出

导出把当前资料的正文、真实引用清单和版本写成明文 YAML 文件，由应用内文件选择保存位置；导入使用应用内文件选择，只用于当前选中的普通记忆、知识或日记。个人事实请在时间线追加更正。

导入先读取整份文件并显示字段、真实引用和受影响资料，确认前不写入；确认后内容、来源链、版本历史与审计一并提交。资料类型、标识、结构版本、锁定状态和共享权限不能通过文件修改。

单个文件最大 24 KB（UTF-8 编码）。要新增一条真实引用，请先单独导出目标资料：引用清单里 resource 填它的「资料类型/标识（id）」，version 填它的 record_version，policy_version 填该导出文件顶层的 policy_version。不要从 URL、说明文字或任务名称猜测数据库记录；缺少引用清单的旧文件不会被当成删除全部来源。

人际关系声明

这里只更正已有关系声明的状态，例如“甲说乙是同事”这类带真实来源的声明。它不是“同一人”的账号关联，也不是好友或群关系：不会新增关系，不改正文、主体、声明人和原证据，也不改同一人的账号关联、回复授权或其他资料权限。

状态只有“仅声明”“已确认”“有争议”“已撤销”。“有争议”仍会由核心带状态返回，“已撤销”不再由核心关系查询返回；已撤销的声明可以再次改回“已确认”或“有争议”，预览会明确提示这是恢复此声明，但不会重新固定来源、不会让已失效或已更换的来源重新可读，也不会自动恢复旧依赖版本。

每次更正都先预览、再确认；预览在锁定、重启、会话改变或声明/来源/依赖变化后失效，取消不写入。每次更正写入一条不可变的加密记录，不会自动删除；本功能开始记录之前的裁决没有记录，本页不会虚构它们。

原证据只在“引用版本与当前一致”时显示正文摘录（每项最多 2000 字，本页合计最多 12000 字，超出会标注截断）；已更换版本、已删除或不支持的类型只说明状态，不用现在的正文冒充当时的证据。只有本机管理员能读取这些内容。

资料共享设置

这里只调整一条资料可以被谁使用，以及是否允许某个已登记账号在私聊中使用这条资料。“回复”用途才允许在私聊回复中使用；“维护”用途只供维护流程使用，不能用于回复。本页不是“允许回复该联系人”：不会授权任何会话、不启动平台、不改变回复额度；要允许回复某个联系人，请使用“持续回复范围”或 QQ／微信的回复名单。

资料的正文、归属账号、真实来源与版本、有效状态和到期时间保持原样。来源被停用、过期或版本改变后，即使共享也不会生效；遇到这种情况本页会如实说明，不会宣称共享可以绕过来源。

共用人物设定（人物卡与基础记忆）仍由“共用人物设定与基础记忆”页的原流程管理；个人事实仍在事实时间线中处理。本页不会改动它们。所有扩大或收回都先预览、再确认；确认只提交本次预览的服务端口令，预览过期、锁定、重启或资料变化后会被拒绝。一条授权可能同时覆盖多条资料，撤销按整条授权生效。

使用模型

模型账号

切换账号会立即停止所有进行中的任务，待旧任务退出后由新账号接手未完成工作；已确认发送的消息不重复发送，结果不明的发送等待核对。添加账号成功后同样执行交接。其他账号的登录保留，额度不足时不会自动换号。

回复额度

私聊按自然日统计回复条数；群聊每次被 @ 或引用唤起算一次参与。保存设置不会调用模型，也不是计费额度。

手动任务

只执行本次提交的任务，不改自动运行设置。取消、停止全部或退出应用会终止任务；换模型账号后由新账号接续未完成步骤。

聊天附件与保留期限

附件从消息处理完成后开始计时；待处理任务和正在使用的附件不会自动清理。手动保存、收藏及表情库素材长期保留。

附件原件空间

空间不足时先清理最旧的已处理普通原件，可能早于保留期限。收藏、手动保存、表情库、未处理和正在使用的原件不会因此删除。无法腾出空间时暂停新附件处理，文字回复继续。

容量按原件内容大小计算，不含应用、模型、备份和数据库额外占用。

QQ 文件正文已接入本机解析；超出整体文本预算时仅提供带出处的片段并说明缺失，不自动追加摘要调用。QQ 图片已接入；动图最多取首、中、尾三帧，每帧占用本轮图片额度，额度不足时减少取帧并注明缺失。QQ 语音由内置本地识别器转写；自动转写可能有同音字、姓名或数字错误，超出时长或文本预算会说明缺失。未提供的内容不会被当作已读取。

备份与恢复

本机备份

恢复会覆盖当前资料；先查看预览，再通过 Windows 验证确认。

换电脑恢复 · 便携备份

导出会把当前全部资料写成一对同名文件：.ccbackup 备份与 .cckey 独立恢复密钥。两个文件必须一起保管，缺一不可。独立恢复口令 16 至 256 个字符，由你自行设置并记住；应用不保存该口令。

导入时先用这一对文件查看来源预览，再通过 Windows 验证，然后完整替换当前资料：两份资料不合并。恢复前会先在本机保全当前资料并显示保全备份名，保全文件不会被自动删除。当前 Windows 管理员绑定与应用密码锁保留，本机平台登录仍留在本机，恢复后全部平台保持停止。全新安装使用同一个入口。

先填写独立恢复口令：导出需要两次输入，导入预览只需要一次。

恢复结果无法确认时，应用会停止后台并提示重启核对，不会自动重复恢复。

本机保全资料

每次完整替换前，应用都先把当时的资料另存为一份本机保全资料，保存在本机资料目录的 history/portable-preservation，不会被自动删除。这里可以读回其中任意一份：先查看预览，再用上面同一个 Windows 确认完成替换。本机保全资料不需要独立恢复口令，也不会读取口令输入框。

列表只显示文件名、文件时间和大小；选中的那份会在预览时完整校验。恢复总是生成新的资料代次，原只读副本与当前资料都保留。
