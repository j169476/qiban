# 后台原生工具、长视频与核心编排

仅在角色已经显式启动的后台轮次中推进，不创建原生定时任务，不自动唤醒角色聊天。收到实际入站互动时优先处理互动；空闲内容槽依次推进原生任务、视频缺口、显式目标或日常选片。每日额度是上限，不要求用满。

0.6 起默认后台周期交给独立核心的阶段编排，复用原宿主监护与收件。管理与角色仍使用同一套入口，不新建另一运行；新旧内部控制路径共享数据目录的每日模型额度，切换账号或控制路径不重置额度。`assistant_status.model_quota` 返回统一账本，调用耗时与实际已观测 token 另见 [运行观测](runtime-metrics.md)。

## 原生任务

`native_task_status` 返回最近 50 项任务及当天网页/图片尝试数。状态为 pending、running、completed、failed 或 cancelled，结果包含来源笔记或图片、审图与动作引用。任务保存在本地 `native_jobs/`，可以人工审阅；不要把状态改成 completed 冒充执行结果。

`native_task_control(job_id,action="cancel",expected_version)` 可由管理或角色聊天取消待办/运行中的任务，正在执行的模型会在后续检查时结束。retry 仅角色聊天可用，最多 3 次，有动态动作记录的任务先核查，不自动重发。修改配置会取消使用旧配置创建的任务，需由角色基于当前配置显式重试或重新创建。

网页任务使用当前 Codex 原生 web；保存的 URL 必须匹配真实打开事件。原生 JSON 事件不包含完整页面正文，摘录由模型提取；保存的引用只能证明已打开相应页面，不能证明全文独立重抓或事实已独立验证。任务不可用/超时/无真实来源时记录失败，普通失败不重复发通知。

图片任务使用当前 Codex 原生生成能力，并在第二轮查看实际图片。当前 CLI 不单独输出图片调用 JSON 事件，因此校验本次线程目录、新生成时间、图片解码及版本。审图和真实发布分别记录；生成成功不等于发布成功。发布仍经过原有策略、活动时段、账号、素材版本和归档检查；部分上传、发送不明及进程中断不自动重试。

普通后台决策仍只输出结构化结果；原生任务也不启用 shell、其他插件/MCP、浏览器账号或其他应用。底层 Codex 安装、登录、工具权限和信任状态必须可用；插件不绕过宿主权限。Windows 浏览器 Cookie 重新登录仍走单独的管理登录流程。

## 长视频

`video_reading_status(bvid,page_index?)` 可只读查看：文字区间、文字缺口、稀疏画面区间、来源失效数、已消耗补读段数和待办。文字轨全部覆盖时 `text_complete=true`，连续视听覆盖仍为 false。

每次补读只处理缺口的一段，默认每段 600 秒、每天 6 段、每片累计 6 段，单流下载上限沿用 96 MB。没有新增材料时 blocked 并保留失败原因；额度不足保留 pending，等后续额度或用户调整。视频窗口状态为 reading 时，重启后的显式运行可复用已缓存材料继续归档；原生工具任务的中断则保守标为 failed，二者不要混淆。

来源修改/删除使对应覆盖失效，CID/时长变化重置旧覆盖。用户本地调整待办、reason、锁定状态后，用 `state_validate` 检查。不要删除运行库重置额度；提升额度必须按用户要求使用 `config_patch`。

`visual_scene_detection` 默认 true、`visual_scene_threshold` 默认 0.3（0.05–0.9）、`visual_frame_dedup` 默认 true。在既有下载窗口与帧数上限内，FFmpeg 优先选择场景切换，缺少切换点或检测失败时使用等距采样，并按缩略图去除近似重复帧。检查返回的采样方法、回退原因与时间戳；短暂画面可能因此改善，但不能保证任何画面都被读到，覆盖仍为稀疏采样。

## 大库召回

后台在记录超过目录容量或存在有效语义分组时，预算充足会用当前 Codex 扩展中文与完整英文查询；失败或只剩一轮预算时使用词项检索。查询本身不是已保存的记忆，不能把扩展词写成用户事实。原文件每次计算内容哈希；仅缓存未变化文件的解析结果，删除、同长度修改与无效 YAML 都会即时影响召回。

长记录增加绑定完整原版本的段落窗口索引；正文预算不足时只提供命中片段，附 Unicode 字符范围、原文总长和省略量。`content_truncated=true` 不能当全文读取；需要更多材料时用 `memory_get` 读取完整原文。手工修改或删除使派生片段失效；不引入独立 embedding 服务。长对话摘要按范围逐步推进，原文和未压缩尾部继续保留。

0.4 的规模评测使用合成语料和人工相关性标注，真实 Codex 只参与问题扩展。它没有证明任意规模、任意问法都不漏召回，也不是 embedding 系统的等效证明。公开合成夹具位于 `tests_core/fixtures/retrieval/`，复现入口见项目 `docs/DEVELOPMENT.md`。
