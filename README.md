# 栖伴 Qiban

**Windows 1.0 正式版** · 栖伴是一款桌面 AI 陪伴应用。你可以在本机的会客室和自己设定的角色聊日常，隔几天再接着上次的话题。也可以连上哔哩哔哩，给角色定一个学习目标，让它带着问题看视频。平时习惯用 QQ 或微信聊天，也能按需连接。

## 过几天，还能接着聊什么？

比如，周末你在会客室说起奶奶留下的旧汤匙：“勺柄弯了，我拿布垫着，一点点把它扶正了。”隔了几天，吃豆花时你又想起来：“我上回是怎么把那把小勺弄直的？”这次说的是“小勺”和“弄直”，要接上话，最有用的线索还是你当时说的那句话。

Windows 安装包自带 **PostgreSQL 数据库**，由栖伴在本机管理，聊天记录和人物记忆就保存在这里。准备回复时，栖伴在当前会话获准使用的记录里结合**关键词检索**和**本地向量检索**查找原话。前者能找到“勺柄”这样的原词，后者按意思找，所以把“扶正”换成“弄直”，仍有机会找到上次的对话。

找回的群聊原话带着发言者信息，角色可以分清是谁提过这件事。聊天继续时，角色也能记下对方明确说过的事，根据后来的交流修正印象。

## 在 B 站学一点，下次散步试一试

举个例子，你把“街头摄影”设成学习目标。假设一段教程演示了对同一场景的亮处、暗处分别测光，角色可以把这项练习和视频出处一起记下来。周五傍晚去桥上散步时，你也试着拍两张：一张对着灯下的亮处测光，一张对着栏杆投下的影子测光。回来就可以接着问角色：“为什么第二张里，远处的天空也变亮了？”

开启 B 站模块后，角色优先读取可用字幕。在设置允许、媒体组件就绪时，也可以转写一段语音，抽取少量画面。保存学习内容时会一并记录视频来源和实际读到的范围，方便以后查到这条经验出自哪一段。

## 第一次走进会客室

本仓库公开源码，完整的 Windows 安装程序在本地构建。拿到安装程序后，按向导安装，再从开始菜单打开「栖伴」。已有免安装版的话，在完整的程序目录里双击 `Qiban.exe` 即可。

1. 打开「模型与档位」，登录自己的 ChatGPT 账号，从账号实际提供的模型和思考档位中选择。
2. 在「人物与记忆」填下人物设定，比如希望角色怎么称呼你、用什么语气聊天。
3. 进入「会客室」，说第一句话。想在其他平台聊天时，再到「平台与会话」连接账号。

日常聊天通过 OpenAI 官方的 **Codex App Server** 接口生成回复。只要 ChatGPT 账号包含 Codex 使用权益，栖伴就可以使用该订阅所含的额度，无需另填 API Key。可用模型和用量限制以当前账号为准。[OpenAI 官方登录说明](https://developers.openai.com/codex/auth/) · [模型选择参考](docs/模型选择参考.md) · [微信支持范围](docs/微信支持范围.md)

## 聊天以外，小屋里还有什么？

像素小屋按当地日期换季，一天分为八个时段。春夏推窗见花叶，秋冬合窗，入夜后亮起床头灯。看向小屋，你可能正好碰上角色写回复、看视频，或是在沙发上读书。

- **统一监控台**能看到哪些平台正在运行、角色手头在忙什么。
- **学习树**可以拉远看全貌，也可以放大到一条笔记继续整理。
- 在**上下文工作台**调整下一次回复会参考的内容，先试算，再应用方案。
