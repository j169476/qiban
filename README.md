# 栖伴 Qiban

本地部署的多平台 AI 伙伴。

开发者：**YiNing和ta的小龙** · [关于、开源许可与使用声明](docs/ABOUT.md)

栖伴是一个 Windows 独立应用。双击 `Qiban.exe` 打开它自己的窗口，管理室、本机会客室和使用手册都在里面，不需要预装 Python、Node.js、PostgreSQL 或编译器，也不用另开浏览器、终端或谁的聊天窗口。角色核心、记忆和加密 PostgreSQL 在本机运行；B 站、微信、QQ 由使用者按需登录、核验和授权。

**当前为 v0.9.4 测试版：代码与插件版本 `0.9.4`，已有的本机安装器版本 `0.9.4.177`。** 面向能自己准备 Windows 环境和平台账号的测试者；功能验收、不同客户端组合和长时间运行仍需在实际使用中自行验证。

## 当前入口

| 项目 | 现状 |
| --- | --- |
| 程序入口 | `Qiban.exe`：双击打开内置窗口；重复启动只激活同一实例；关窗收至托盘 |
| 内置界面 | 管理室、本机会客室、内置用户手册；不打开管理网页，不需要聊天 ID |
| 首次启动 | 自动建立空白资料与本安装自己的加密数据库；本机管理员默认是当前 Windows 登录用户，应用密码锁可主动启用 |
| 平台接入 | B 站、微信、QQ 都在应用内按需登录与核验，再逐条授权会话 |
| 平台运行 | **默认停用**：新安装不启动任何平台，微信与 QQ 默认不回复任何会话 |
| 更新与分发 | 无联网更新源；安装包未做代码签名，也还没有公开可下载的安装包 |

## 能力与边界

| 模块 | 当前能力 | 部署条件 |
| --- | --- | --- |
| 共享核心 | 人物卡、基础记忆、会话记忆、资料权限、预算、动作账本、备份恢复 | 随应用启停的本机服务与加密 PostgreSQL |
| 管理 | 应用内管理室与本机会客室，共用同一本机管理员身份 | 当前 Windows 登录用户；应用密码锁可选 |
| B 站 | 内容阅读、互动、私信与角色学习工作流 | 在应用内自行登录账号，按平台策略与额度运行 |
| 微信 | 加密数据库只读收件、最小化窗口下受限原生文本发送 | 需要本机已准备并核验的原生发送桥接；精确版本／文件指纹限制；自行登记账号和测试会话 |
| QQ | 原生收件和回复、扫码登录、账号核验与断线重连 | 需要与锁定版本一致的本机 QQ 运行资源及独立账号 |

微信和 QQ **默认不回复任何会话**。只有管理端明确授权的稳定会话 ID 可进入回复流程。私聊直接回应并使用独立额度；群聊由真实 @ 或经核验的引用唤起有限参与阶段，话题结束或额度用尽后等待再次唤起。启动、登录、授权和资料读取权限是不同的控制项：登录平台不等于允许它运行或回话，首次建库和角色恢复也不代表平台自动活动。

本项目不附带登录会话、账号白名单、数据库、数据库密钥、个人记忆、用户上传的角色图片、QQ 桥接或 QQ 客户端二进制、微信客户端。启动服务或恢复备份不会自动恢复角色活动。

## 本轮发布与分发的边界

- 当前候选完整包是本机验证用的构建产物，**不等于公开附件**；不提供安装包或完整包的下载地址，也没有新建 release。
- 安装器与完整包**未做代码签名**（构建记录为 `signed=false`）；代码签名与公开资产发布均未完成。
- QQ 原生运行时需要**已核验的本机资源**，它的再分发审查仍未完成：不声称可公开随包分发，也不声称应用会自动获取。
- 72 小时长时运行已移出本轮发布门槛（2026-11-13 决定）。要求与后续轮次安排保留；本轮不以缺少该证据判为失败，但也不能据移出声称长时运行已经通过。

## 从这里开始

1. 阅读 [安装与首次启动](docs/GETTING_STARTED.md)，装好或打开本机应用，完成首次建库。
2. 在应用内的管理室填写空白人物卡、基础记忆和外观参考；用内置用户手册对照页面。
3. 按需接入 B 站、QQ 或微信，核验账号和目标对象。
4. 核对会话授权范围，再开启要运行的平台。

旧版浏览器管理页与 Codex 插件入口已经退役，仓库里保留的这几份说明属于**旧版入口／开发参考**，以应用内页面和用户手册为准：[角色与资料配置](docs/CONFIGURATION.md)、[QQ 模块](docs/QQ_MODULE.md)、[微信模块](docs/wechat-module.md)、[统一会话回复授权](docs/CONVERSATION_REPLY_AUTHORIZATION.md)、[架构](docs/ARCHITECTURE.md)。开发者另见 [测试与发布](docs/DEVELOPMENT.md)、[测试版说明](docs/RELEASE_NOTES.md) 和 [第三方许可说明](THIRD_PARTY_NOTICES.md)。

包名与插件 ID 统一为 `qiban`；旧的 `bili-assistant` 命令和内部连接器模块仅作兼容来源保留，`python -m qiban` 与旧插件启动器现在只输出退役提示并以非零码退出。管理界面附带白龙娘插画与 SVG 图标，不写入用户人物卡。

## 源码构建

源码仍可自行构建完整应用（Windows 独立应用外壳、内置存储后台、内嵌 PostgreSQL 资源，再组装并编译安装包）；步骤与参数见 [安装与首次启动](docs/GETTING_STARTED.md) 的“从源代码构建”一节和 `scripts/desktop_probe/README.md`。构建需要自备 PostgreSQL 完整分发目录、WebView2 与 .NET 桌面构建环境、官方 Inno Setup；微信原生发送桥接与 QQ 桥接各自还要本机准备资源。
