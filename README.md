# 栖伴 Qiban

**Windows 1.0 正式版** · 栖伴是一款桌面 AI 陪伴应用。你可以在本机的会客室和自己设定的角色聊天，也可以按需连接 QQ、微信和哔哩哔哩。

## 第一次走进会客室

本仓库公开源码，完整的 Windows 安装程序在本地构建。拿到安装程序后，按向导安装，再从开始菜单打开「栖伴」。已有免安装版的话，在完整的程序目录里双击 `Qiban.exe` 即可。[Linux 后续开发预留入口](platforms/linux/README.md)

1. 打开「模型与档位」，登录模型账号，选择模型和它提供的思考档位。
2. 在「人物与记忆」填下人物设定，比如希望角色怎么称呼你、用什么语气聊天。
3. 进入「会客室」，说第一句话。想在其他平台聊天时，再到「平台与会话」连接账号。

[模型选择参考](docs/模型选择参考.md) · [微信支持范围](docs/微信支持范围.md)

## 聊天以外，小屋里还有什么？

像素小屋按当地日期换季，一天分为八个时段。春夏推窗见花叶，秋冬合窗，入夜后亮起床头灯。看向小屋，你可能正好碰上角色写回复、看视频，或是在沙发上读书。

- **统一监控台**能看到哪些平台正在运行、角色手头在忙什么。
- **学习树**可以拉远看全貌，也可以放大到一条笔记继续整理。
- 在**上下文工作台**调整下一次回复会参考的内容，先试算，再应用方案。
