# 栖伴 Qiban

栖伴是一套面向 Windows 的开源 AI 陪伴系统。项目将对话记忆和视频学习记录保存在本机，使角色在后续交流中能够引用早先的对话，并保留所学内容的来源。Windows 1.0 提供本机会客室，并支持按需连接 QQ、微信和哔哩哔哩。

## 对话记忆与历史检索

Windows 安装包附带独立的 PostgreSQL 数据库，由栖伴在本机管理。系统分别保存聊天原文和人物记忆。生成回复前，检索范围限于当前会话有权读取的历史记录。关键词检索匹配原文用词，本地向量检索寻找含义相近的表达。系统综合两种排序，选取相关片段作为本轮回复的参考。[历史检索实现](src/companion_core/hybrid_history.py)

群聊片段保留发言者信息，以便区分同一话题下不同人的表述。在私聊中，当用户明确更正先前陈述的个人事实时，系统可记录新旧陈述之间的替代关系，并按生效时间判断哪条记录适用于当前对话。

## 视频材料与学习记录

哔哩哔哩模块按学习目标选取视频材料，优先读取可用字幕。配置允许且本地媒体组件就绪时，模块还可对选定片段进行语音转写或画面抽样。保存知识记录时，系统一并记录视频来源与实际覆盖范围，便于核对结论所依据的材料。[视频材料处理](src/bili_assistant/video_material.py)

学习树按目标组织学习内容，支持缩放浏览和编辑笔记。树的布局在后台计算，对话生成无需等待布局完成。

## 模型接入与数据边界

普通对话通过 OpenAI 官方的 Codex App Server 生成回复。用户在栖伴内登录具有 Codex 使用权益的 ChatGPT 账号，即可使用订阅所含额度，无需另填 API Key。可用模型、思考档位和用量限制取决于当前账号。[OpenAI 登录说明](https://developers.openai.com/codex/auth/) · [模型选择参考](docs/模型选择参考.md)

个人资料、聊天记录和备份保存在本机。使用云模型时，栖伴会将本轮回复所需的聊天片段、记忆及其他上下文发送给所选模型服务。[使用与隐私声明](docs/桌面声明.md)

## 使用入口

本仓库提供源码，完整 Windows 安装程序在本地构建。安装后从开始菜单打开「栖伴」，免安装版从完整程序目录中的 `Qiban.exe` 启动。

首次使用时，在「模型与档位」登录账号，在「人物与记忆」设置角色，然后进入「会客室」开始对话。「平台与会话」用于连接其他平台，「统一监控台」显示各平台的运行状态。「上下文工作台」用于试算、保存和应用回复方案。[微信支持范围](docs/微信支持范围.md)
