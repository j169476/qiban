# 栖伴 Qiban

栖伴是一款在 Windows 上运行的多平台 AI 陪伴应用。你可以在本机会客室聊天，也可以连接 QQ、微信和 B 站，让角色通过对话和视频逐步积累记忆。人物设定、聊天记录和备份保存在本机。

**当前桌面版为 0.9.9.4。** 从安装包安装后，可以在开始菜单打开「栖伴」。免安装版的入口是 `Qiban.exe`。本仓库分发源码，完整安装程序在本地构建。

- **监控台**显示各平台的运行状态、当前活动和生效的上下文方案。
- **平台与会话**用于登录账号、同步联系人和选择回复对象。
- **模型与用量**用于登录模型账号、选择模型与思考强度、设置额度。
- **上下文工作台**用于制作和试算方案，也可以查看各个方案发出的回复。
