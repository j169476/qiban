# 栖伴 Qiban

本地部署的多平台 AI 伙伴。

开发者：**YiNing和ta的小龙** · [关于、开源许可与使用声明](docs/ABOUT.md)

面向个人电脑部署的角色助手，共用一套角色核心和加密 PostgreSQL，通过独立连接器接入 B 站、微信、QQ，也提供本机会客室。软件名为“栖伴 Qiban”，新安装的角色名称、人物设定、基础记忆和头像均为空，由使用者自行填写。

**当前测试版本为 v0.9.4，代码与插件版本为 `0.9.4`。** 面向能自行配置本地环境的测试者；功能验收、不同客户端组合和长时运行仍需在实际使用中验证。

v0.9.4 修复首次初始化入口，补齐服务恢复的等待预算与脱敏阶段诊断。v0.9.3 已增加网页中英文切换、双语用户手册、联系人独立每日额度和对象齿轮编辑；优化普通聊天处理流程，补齐 NapCat 托管启停及公开成长恢复。管理室与会客室顶部均可打开用户手册。更新细节见 [本版说明](docs/RELEASE_NOTES.md)。

## 能力与边界

| 模块 | 当前能力 | 部署条件 |
| --- | --- | --- |
| 共享核心 | 人物卡、基础记忆、会话记忆、资料权限、预算、动作账本、备份恢复 | 本地服务与 PostgreSQL |
| 管理 | 登录网页和独立后台管理聊天，共用配置与授权接口 | Codex 宿主身份；网页使用独立管理员登录 |
| B 站 | 内容阅读、互动、私信与角色学习工作流 | 自行登录账号，按平台策略与额度运行 |
| 微信 | 加密数据库只读收件、最小化窗口下受限原生文本发送 | Windows；精确版本/文件指纹限制；需自行登记账号和两条测试会话 |
| QQ | OneBot v11 收件与文本回复、账号核验、断线重连 | 自行部署兼容桥接，配置独立机器人账号 |

微信和 QQ **默认不回复任何会话**。只有管理端明确授权的稳定会话 ID 可进入回复流程。私聊直接回应并使用独立额度；群聊由真实 @ 或经核验的引用唤起有限参与阶段，话题结束或额度用尽后等待再次唤起。启动、授权和资料读取权限是不同的控制项。

本项目不附带登录会话、账号白名单、数据库、数据库密钥、个人记忆、用户上传的角色图片、QQ 桥接二进制或微信客户端。启动服务不会自动恢复角色活动。

## 从这里开始

1. 阅读 [安装说明](docs/GETTING_STARTED.md)，在自己的目录创建环境与本地服务。
2. 按 [角色与资料配置](docs/CONFIGURATION.md) 填写空白人物卡、基础记忆和外观参考。
3. 按需接入 [QQ](docs/QQ_MODULE.md) 或 [微信](docs/wechat-module.md)，核验账号和目标。
4. 在 [统一会话回复授权](docs/CONVERSATION_REPLY_AUTHORIZATION.md) 中逐条授权，再明确启动相应平台。

开发者可查看 [架构](docs/ARCHITECTURE.md)、[测试与发布](docs/DEVELOPMENT.md)、[测试版说明](docs/RELEASE_NOTES.md) 和 [第三方许可说明](THIRD_PARTY_NOTICES.md)。包名与插件 ID 统一为 `qiban`，旧 `bili-assistant` 命令和内部连接器模块保留兼容。管理界面附带白龙娘插画与 SVG 图标，不写入用户人物卡。
