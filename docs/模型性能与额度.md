# 栖伴回复耗时与积分成本

Windows 0.9.7.4 默认使用本地关键词和向量召回旧聊天。在仅需检索旧聊天的八题对照中，GPT-5.6-Luna / low 的回复完成中位数为 **11.04 秒**。另用同一模型做三题成对复测，按上游报告的 token 和官方费率折算，每条回复平均 **0.05690 credits**。实测和费率核对日期均为 2026-11-19。

## 旧聊天召回的版本对照

| GPT-5.6-Luna / low | 八题正文首字中位数 | 八题完成中位数 | 八题答对 | 每题云端调用 | 三题平均积分／条 |
|---|---:|---:|---:|---:|---:|
| 旧流程，云端扩写后按关键词召回 | 19.96 秒 | 20.77 秒 | 7/8 | 2 | 0.06662 |
| 0.9.7.4，本地混合召回 | 9.92 秒 | 11.04 秒 | 8/8 | 1 | 0.05690 |

八组各自相减，每题节省时间的中位数为 **9.59 秒**。时间从栖伴开始处理消息起算，包含本地读取、模型请求和本地模拟投递。八题覆盖群里同问不同人、改期、撤销和询问他人。正式后台共用同一份编码模型，账号使用的云端回复模型和思考强度仍由用户选择。[八题逐次计时和原话](benchmarks/旧聊天混合召回试点实测.json)

### 三题积分复测

每格 token 数均汇总了一条回复实际发生的全部云端调用，依次为未缓存输入、缓存输入和输出。

| 问题 | 旧流程 token | 旧流程积分 | 混合召回 token | 混合召回积分 |
|---|---:|---:|---:|---:|
| 乙问自己的薄荷叫什么 | 12,590 / 6,144 / 335 | 0.076072 | 5,862 / 6,144 / 184 | 0.037902 |
| 木刻课取消，新日期待定 | 13,419 / 6,144 / 203 | 0.076257 | 12,792 / 0 / 142 | 0.068220 |
| 甲更正自己的摊位编号 | 6,959 / 11,776 / 228 | 0.047523 | 11,997 / 0 / 153 | 0.064575 |

三题平均积分下降 **14.6%**。摊位编号一题中，旧流程命中了 11,776 个缓存输入 token，混合召回这次缓存命中为零，因此少一次云端调用仍花了更多积分。当天此型号每百万未缓存输入、缓存输入、输出 token 分别计 5、0.5、30 credits。折算时从总输入中扣除缓存输入，输出已含推理 token。套餐实际扣款与剩余额度以账号用量页为准。[三题逐调用 token 与计时](benchmarks/混合召回积分实测.json) · [OpenAI 官方积分费率](https://learn.chatgpt.com/docs/pricing#token-rates)
