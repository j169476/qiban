# 首个对外测试版 · v0.8.0-test.1

发布标识用于区分测试状态；Python 包、核心和插件保持 `0.8.0`，独立 QQ/微信连接器保持各自版本。尚未发布稳定版兼容承诺。

包含共享角色与记忆核心、加密 PostgreSQL 本地服务、管理网页与后台管理聊天，以及 B 站、微信、QQ 和本机会客室入口。微信和 QQ 使用统一的默认拒绝会话授权、私聊额度和群有限参与策略。连接器与核心分离，账号、收件游标和发送动作有各自核验边界。

本次公开整理移除开发交接文档、个人实测记录、人物卡和头像素材。初始化角色名称、描述、表达风格、兴趣和基础记忆全部留空，不包含外观与关系预设。合成检索数据保留在测试目录。

## 已知限制

- Windows 是当前本机服务安装和微信接入的目标环境；没有完成跨系统部署验收。
- 新安装需自行准备 PostgreSQL、平台账号与可用 Codex 宿主。QQ 桥接和微信原生构建不是一键安装。
- 微信受精确客户端指纹限制，目前登记一个私聊和一个群聊；只支持受限文本发送。
- QQ 协议端需使用者自行部署；不同桥接、客户端更新和多账号组合需实际验证。
- 群参与判断、话题结束和角色表达存在模型不确定性；额度与授权仍由程序强制检查。
- 已有自动化测试与有限实机验证不替代后续功能验收和长时运行。发布准备不会再自动发送验收消息。
