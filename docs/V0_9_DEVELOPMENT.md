# Qiban v0.9 开发与验收约定

## 开发与交付目录

- 外层项目根目录 用于修改、测试和本机开发。
- 内层 `qiban/` 是干净的提交目录。验证后的交付文件再整理进入该目录。
- 不覆盖两套安装的数据目录、账号资料、运行配置或已有开发改动。

## 已确认的运行规则

| 操作 | 行为 |
| --- | --- |
| 切换、关闭聊天视图 | 已启动任务保持运行 |
| 关闭浏览器管理页 | 已启动任务保持运行 |
| 归档某个聊天 | 停止该聊天拥有的平台任务 |
| 退出 Codex 应用 | 接受后台与数据库随宿主一同结束；关键状态运行中提交，不承诺退出回调完成。网页断线时显示“暂时无法连接本机服务”，仅在服务确认宿主已退出时显示“ChatGPT已停止运行” |
| 再次打开 Codex | 不自动恢复；用户在管理聊天明确重启，或自行通过命令行重启 |
| 浏览器仍能连接本地服务 | 可查看状态、修改配置；运行操作明确显示宿主是否可用 |

正常退出与异常终止分别验收。异常终止不保证有机会执行退出回调：关键状态应事先持久化，恢复时核对中断任务，发送结果不确定的动作不得自动重放。网页断线不等于已证实 Codex 退出，界面须分别显示两种状态。

## 实施范围

1. 统一软件、插件、技能及安装文档中的 Qiban 命名。B 站连接器的真实平台名称保留。旧入口与数据路径按迁移规则处理，不能通过盲目替换创建另一套数据。
2. 独立浏览器管理页面与 Codex `@qiban` 入口使用同一服务、权限和运行状态。网页可管理平台与任务；恢复运行遵守上述规则。
3. 管理页面采用分类导航：总览、平台与会话、角色与记忆、任务、用量、系统设置。保留已有能力，整理主次操作，修复遮挡、溢出、点击区域与视觉位置不一致等问题。
4. 运行监控展示实际任务状态、模型调用与可观测 token。账户余额、实际费用和估算值必须分别标明来源；未知值不能显示成零。
5. 根据用户提供的白龙娘参考图设计背景、空状态与反馈素材。装饰不覆盖按钮、输入框和可读内容；界面美术与用户可编辑人物卡分别管理。

## 已确认范围与实机验证

- 额度分为本地回复/模型上限、Codex 账户共享 coding plan 百分比、Qiban 观测 tokens。货币余额不在此范围；未知值不作零处理。
- 产品版本 v0.9，Python 主包、核心、Codex 桥接与插件版本统一 `0.9.0`。
- Windows 实机退出/重开已验证：本轮服务树与既有另一实例的进程全部退出，管理端口无监听，数据库同时结束；正常关闭标记未写入。用户接受此行为，不引入独立 Windows 后台服务。此次平台始终暂停，未覆盖真实发送中退出。
- 插件已安装为 qiban，旧入口停用；重开 Codex 后已加载 qiban 命名空间。

## 验证要求

- 在隔离测试数据上验证运行控制、归档、宿主失联、显式恢复及重复请求。
- 使用合成数据验证管理页面桌面/窄屏布局、导航、键盘操作与按钮命中，不触发真实平台外发。
- 验证插件及 Python 包版本一致、静态素材随包发布、旧安装资料不丢失。
- 整理至干净目录前运行发布审查，排除本机配置、凭据、数据库与私人历史。
