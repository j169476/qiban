# Windows 个人版安装与首次使用

在 Windows 本机与角色对话，按下文安装个人版。要从 Windows 查看 Ubuntu 后台，请使用独立的远程控制台。[远程控制台使用说明](../platforms/windows-remote/README.md) · [Ubuntu 后台说明](../platforms/linux/README.md)

## 打开栖伴

运行本版 Windows 安装程序，按向导选择程序目录。安装完成后，从开始菜单打开「栖伴」。使用免安装版时，保留整个程序目录，双击其中的 `Qiban.exe`。

首次打开时，栖伴会创建本机个人资料和加密数据库。等待监控台显示后台已连接，即可开始设置。

## 开始聊天

1. 在「模型与档位」登录模型账号，选择模型和思考强度，设置额度。
2. 在人物与记忆页面填写人物设定。打开会客室即可在本机聊天。
3. 要在其他平台接收回复，在「平台与会话」登录对应账号。QQ 和微信可同步联系人，按昵称或备注搜索并选择回复对象。
4. 在监控台启动平台。需要随应用启动时，勾选「下次打开时自动运行」。

[微信支持版本](微信支持范围.md) · [模型速度与积分参考](模型选择参考.md)

## 查看角色正在跟进的事

监控台的「最近行动」按最近变动列出最多十条事项。点事项标题可直接打开该条记录，点「查看事项」可进入完整列表。消息行动会显示可用的收件会话短标。「等待新消息」表示事项正在等消息。「等待唤醒」旁的日期和时间按本机时区显示。

事项进度与投递回执分别显示。看到「已停止 · 投递已确认」，表示后续处理已停止，先前的消息已确认投递。「投递结果不明」表示尚无确定回执。在「角色提醒」中展开记录，可查看到期时间，并按该条记录提供的操作改期或取消。

## 核对一条资料的使用范围

打开「人物与记忆 → 资料共享」，展开「隐私使用范围」。也可以先选中一条记忆、知识或日记，再点「查看此资料的隐私范围」。同条资料中的活动安排、场馆地点和个人行程可能有不同受众。展开片段即可查看当前受众，有可更正的范围时可选择后保存。等待后台审查的片段保留原范围，凭据只显示遮盖后的记录。

## 调整回复方案

在上下文工作台新建方案，或选中已有方案后点「加载」。编辑名称和内容后可以试算、保存。点「应用方案」后，下一次回复使用新方案。监控台显示生效名称，「回复记录」可以按方案查看已发送的内容。

## 退出、备份与更新

点击窗口关闭按钮，可选择退出或在后台运行。退出应用会关闭本机后台。

更新前可在「设置与备份」保存个人资料，退出应用后运行新安装包。卸载准备页默认保留个人资料，也可以勾选清空。需要保留的导出备份请放在个人资料目录以外。
