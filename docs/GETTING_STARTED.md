# 安装与首次使用

## 打开栖伴

运行本版 Windows 安装程序，按向导选择程序目录。安装完成后，从开始菜单打开「栖伴」。使用免安装版时，保留整个程序目录，双击其中的 `Qiban.exe`。

首次打开时，栖伴会创建本机个人资料和加密数据库。等待监控台显示后台已连接，即可开始设置。

## 开始聊天

1. 在「模型与档位」登录模型账号，选择模型和思考强度，设置额度。
2. 在人物与记忆页面填写人物设定。打开会客室即可在本机聊天。
3. 要在其他平台接收回复，在「平台与会话」登录对应账号。QQ 和微信可同步联系人，按昵称或备注搜索并选择回复对象。
4. 在监控台启动平台。需要随应用启动时，勾选「下次打开时自动运行」。

[微信支持版本](微信支持范围.md) · [模型速度与积分参考](模型选择参考.md)

## 调整回复方案

在上下文工作台新建方案，或选中已有方案后点「加载」。编辑名称和内容后可以试算、保存。点「应用方案」后，下一次回复使用新方案。监控台显示生效名称，「回复记录」可以按方案查看已发送的内容。

## 退出、备份与更新

点击窗口关闭按钮，可选择退出或在后台运行。退出应用会关闭本机后台。

更新前可在「设置与备份」保存个人资料，退出应用后运行新安装包。卸载准备页默认保留个人资料，也可以勾选清空。需要保留的导出备份请放在个人资料目录以外。
